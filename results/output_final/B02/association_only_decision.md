# B02 Association-path reporting decision

The final analysis reports only the four design-adjusted association paths a, b, c and c-prime. It does not report a coefficient-product indirect effect, a proportion mediated, or a causal mediation effect.

A linear a path cannot be multiplied by a logistic b path and interpreted as an indirect effect for a binary outcome. Any future quantitative mediation analysis would require a separately specified probability-scale procedure and the full variance calculation inside the replicate design. It is intentionally outside this release.
