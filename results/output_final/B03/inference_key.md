# Inference key

- `TableS3_missingness_and_complete_case_sensitivity.csv`: at-least-one, at-least-two, and all-three item analyses have Fay-BRR 95% confidence intervals; MNAR delta scenarios have point estimates only.
- `TableS4_multiple_imputation_design_brr.csv`: confidence intervals combine within-imputation Fay-BRR variance with between-imputation variance using Rubin's rules.
- No table in this package labels a model-covariance-only confidence interval as design based.
